# 桌面执行与经验录制

## 录制、编译和使用桌面经验

1. 在“录制环境”选择“本机桌面 · 主显示器跨程序录制”，填写经验名称。
2. 可开启原有语音讲解。确认主屏录制提示后，3 秒开始录制；可在多个程序间切换。
   F8 标记完成，F9 或网页停止按钮取消。只录主显示器，请勿跨到第二块屏幕操作。
3. 复用原有编译、讲解审查及任务确认流程，也可勾选稍后编译。
   Compiler 会被告知这是跨应用录制，需要在状态与转换中识别对应应用。
4. 执行范围选择“整个桌面”，开启“使用经验”，手动选择已语义编译且确认的经验。
   可先“只生成计划”，确认后执行。

桌面执行读取语义任务说明、有向状态图及已确认的人工 Guidance 规则。
原始动作坐标、按键轨迹和录制文本不作为可回放程序发送给执行模型；当前坐标从当前截图推断。
也可以选择已有单窗口语义经验，但只把它当作对应应用内的指导，不能泛化到其他应用。
本版采用文本经验指导，不额外发送录制参考图；桌面运行的自动反馈归档尚未接入。
开启经验的运行日志目录为 `runs/*-desktop-agent/`，会记录实际加载的经验上下文。

## 无经验 Baseline

重启网页后台后，在“执行任务 → 执行范围”选择“整个桌面 · 主显示器”。
关闭“使用经验”后，无需录制、编译、选择或确认任务包。填写指令，选择 Codex、模型 API 或本地模型，
可以先“只生成计划”，再“开始执行”。例如：打开记事本，输入 hello。

- 不检索或发送 Trace、Compiler 状态图、人工反馈经验；仅发送通用动作规则、
  本次指令、当前主屏截图和最近 8 个已执行动作。每轮重置模型上下文。
- 支持主屏上的跨程序点击、双击、输入文字、按键、组合键和等待；
  可点击任务栏或用 Alt+Tab 切换，Ctrl+Esc 打开开始菜单，Page Up/Down 翻页。
- 每轮最多规划 4 个动作；点击、等待或前台窗口切换后丢弃剩余批次并重新截图。
  第一版以可检查的 Baseline 为目标，不保证与经验模式同样的吞吐量。
- 最多执行 80 个动作。F9 或网页停止按钮取消；模型等待期间也可取消。
  规划期间或下一动作前焦点/主屏分辨率改变，会丢弃未执行计划并重新截图规划；
  连续 3 次变化且没有成功执行动作才停止，不向已改变的窗口发送旧计划。
- 仅支持前台主显示器。不支持后台并行、其他显示器、锁屏、UAC 安全桌面或提权。
  运行期间不要同时使用鼠标键盘。请先关闭私人或敏感窗口；截图会发给所选模型。
- 日志保存在 `runs/*-desktop-baseline/`：`trace.jsonl` 包含提示、回答及执行动作，
  `frames/` 为截图，`summary.json` 为结果。不会生成或更新经验。
- 网页显示每轮模型请求耗时、每个动作耗时及每 10 秒的等待提示；结果含性能时间轴，
  分列截图、模型请求、本地动作、显式等待和各轮规划。失败/取消也保留累计耗时。
  模型请求耗时包含网络、排队和生成，并非纯推理耗时；总耗时还包含启动倒计时等开销。
- 模型自报完成标记为 `model_reported_complete`，`verified` 始终为 false。
  这不是 WAA 官方评测结果，也不能直接与不同动作预算/环境的实验比较成功率。

原有单窗口执行和“使用经验”开关保持不变。

## 统一执行入口

“执行范围”和“使用经验”是两个维度：单窗口和桌面均可选择使用经验或 Baseline。
桌面任务包不能送到单窗口执行器；桌面选择经验目前须手动指定，不自动匹配。
切换范围不会清除模型/API 设置，
返回单窗口时恢复原来的经验开关及前后台设置。

两种范围统一经过网页 `/api/jobs` 和同一个任务工作线程入口。
`execution_runtime.py` 共享截图计时、可取消模型规划、等待提示、动作预算、
停止检查及动作耗时日志；输入仍在注册停止热键的调用线程执行。
范围特有的编排保留在适配器中：单窗口继续使用状态图、经验、效果验证与批次恢复；
桌面使用主屏坐标、跨窗口观察与过期计划丢弃策略。
本次没有把两个不同的状态机强行改成同一套策略，也没有迁移已有任务包。
