# ChatGPT 内置浏览器（实验）

在开发版工作台左侧点击“ChatGPT 网页”，再点击“打开 ChatGPT 登录窗口”。“模型与连接”页顶部也提供跳转入口。这是 Trace2Task 自己的 WebView2 小窗口，可在其中手动登录。标题栏显示当前站点域名；“浏览”菜单提供后退、前进、刷新、回到 ChatGPT 首页和关闭。

浏览器使用数据目录下独立的 `auth/chatgpt-browser/` 保存 Cookie 和网页存储。关闭窗口、退出工作台或重新打开窗口不会删除这份会话；网站自身仍可能要求重新登录。该目录属于本机登录数据，不应进入源码、任务包、运行记录或对外导出的附件。

网页在独立进程中运行，没有执行器或 Python API 注入。工作台通过专属管道接收窗口和页面加载状态，只显示域名与网络错误；不会把对话路径、登录回调参数、Cookie、令牌或页面正文写入状态接口。没有新增监听端口。关闭工作台时会关闭它启动的浏览器进程，保留浏览器数据。

这是登录与网页连通性入口，**尚未实现 ChatGPT 网页模型推理接口**。页面已加载不代表已登录，也不代表模型已连接。目前不会把该浏览器加入任务模型列表，不会自动上传截图、提交提示或执行模型动作。后续接入需要在登录后验证实际的图片上传、会话续接和模型输出协议。
