# 发布前审查：2026-09-22

范围：当前 Windows 桌面控制台、执行边界、本地模型服务、安装入口、模型下载与发布文件。
这是代码与离线回归审查，不是模型能力评测，也不是所有应用的真实桌面验收。

## 已修复

| 问题 | 修复与回归证据 |
|---|---|
| 启动一个本地模型会关闭其他模型服务；配置有误时也先关闭正常服务 | 按所选服务分类停止，先校验启动依赖；`tests/test_local_model_service.py` |
| Windows 虚拟环境启动器与实际 Python 的 PID 不一定相同，启动失败可能遗留模型进程 | 清理仅限本次创建且仍存活的 Popen 进程树，Windows 使用精确 PID + `/T`；`tests/test_local_process.py` |
| D 服务开始监听不等于权重已加载，客户端可能过早预测 | health 区分 `loading/ready`，客户端等待 ready；禁止本地请求 HTTP 重定向；模型客户端/预览测试 |
| 部分网页写接口缺少统一跨站保护，GET 也未检查本机 Host | 所有 POST 要求本机 Host、同源 Origin、服务令牌和 JSON；GET 要求本机 Host；`tests/test_web_console.py` |
| 浏览器安全策略阻止动作预览的标注图 | 仅允许图片使用 `data:`，不放开外部脚本、网络、表单或嵌套页面 |
| Cua 目标身份、截图尺寸、控件树不合法时仍可能进入动作转换 | 严格验证窗口及宿主身份和协议；窗口变化时拒绝旧计划；Cua 身份/范围/后端测试 |
| Cua 动作已送达但效果不可确认后仍继续规划 | 记录不确定结果后停止，不自动重试；`test_cua_scope.py` 的执行回归 |
| CLI 桌面入口绕过单实例和数据目录保护；早期配置错误缺少错误窗口/日志 | CLI 与安装版统一入口；损坏设置允许重新选择；设置原子保存；`tests/test_desktop_app.py` |
| 缓存下载清单未核对固定 revision，下载文件替换早于哈希验证 | 校验仓库/revision/安全文件名，下载完成且哈希匹配后才替换；`tests/test_local_gui_download.py` |

没有移除用户任务、经验、录音、日志或 D 盘模型；没有为审查运行真实桌面动作或 GPU 任务。
Windows 启动器 PID 行为用一个仅打印自身 PID 后退出的 Python 子进程核实；进程清理回归全部使用模拟进程。

## 验证与发布边界

- 本机 Windows / Python 3.12 全量测试：531 通过、4 跳过（缺少创建符号链接权限）；6 项 Node 测试、Ruff、JavaScript 语法、锁文件一致性与差异格式检查通过。图片预览测试已实际运行。
- Dev 依赖加入 Pillow，让截图标注/预览 HTTP 测试不再因缺少 Pillow 跳过。
- 锁文件统一到默认官方 PyPI 索引以匹配 `uv sync --locked` 和 CI；其余已锁定包的版本保持不变。
- 提供 [Windows GitHub Actions 回归模板](ci/windows-regression.yml)，覆盖全量离线测试及前端/静态检查，不下载模型或启动 VM。当前推送凭据不含 `workflow` 权限，因此模板暂不放入 `.github/workflows/`，**尚未自动运行**；有对应权限后可再启用。现有工作流未改动。
- 发布内容仅源码、文档与构建脚本，不包含运行记录、密钥、模型权重或安装包。

## 仍需后续验证

- Cua 为实验后端；后台输入兼容性、游戏、最小化窗口不能视为通用支持。
- 模型服务控制入口与客户端使用独立启动锁，仍可能同时尝试绑定同一端口；独占绑定和清理自身子进程限制冲突，但尚未统一生命周期管理器。
- 本地固定路径仍是开发环境默认值；新机器需要配置外部 CUDA 环境、模型及驱动。
- 本次不重建/安装二进制。已有安装包不自动获得源码修复，需另行构建、启动及卸载验收。
- 确认动作已送达、模型输出 `done`、测试通过，均不等于真实任务已被独立验证成功。
- 日志保留任务、截图和实际输入输出，可能包含隐私；本机接口保护不能防御同账户恶意软件。
