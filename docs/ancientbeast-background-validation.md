# Ancient Beast 后台浏览器资格验证

日期：2026-10-13。结论：**通过有限的后台交互验证，已接入源码版工作台的实验性浏览器后端；尚未完成真实模型完整对局、RSI 或胜率验证。**

## 路径和边界

- 官方站点 `https://ancientbeast.com/`，界面版本 `v0.5.1-α`。
- 使用已有 Playwright 1.63.0 与本机 Edge，无头模式，独立临时浏览器上下文，1280×800、deviceScaleFactor=1。
- 只使用页面截图、坐标点击、悬停、按键；没有 DOM、可访问性树、JavaScript 求值、游戏状态读取或游戏动作 API。
- 没有调用 Cua、Win32 键鼠、真实鼠标移动或前台激活。系统进程检查确认浏览器带有 headless 与临时 profile 参数；没有做连续桌面焦点监测，因此不声称已量化所有系统级干扰。
- 本次决策由当前助手看图作出，不是 Trace2Task 工作台中的已接入 Agent，也不是人类示范录制。不能把这批动作标为人类 A 或 Trace Compile B。
- 只测试了默认本地对局，没有连接真人房间、登录或购买。

## 可复用探针

仓库根目录运行：

```powershell
node scripts/browser_game_probe.mjs
```

进程从标准输入逐行接收 JSON，逐步返回截图路径。例子：

```json
{"op":"goto","url":"https://ancientbeast.com/","wait_ms":5000}
{"op":"observe","wait_ms":5000}
{"op":"close"}
```

先看新截图，再选择 click/move 的 x、y 或 key；示例不提供盲目重放的游戏坐标。支持的键以脚本白名单为准。

探针只允许官方域名 HTTPS 导航，拒绝越界坐标、未知操作和未知按键，不提供 DOM/evaluate 接口。下载关闭，弹窗自动关闭；不使用用户持久浏览器资料。最多 120 个命令、20 分钟，EOF 或 close 释放自己的浏览器。输出目录必须不存在，避免覆盖已有证据。

后续完善的探针为截图记录 SHA-256、浏览器版本与动作尝试；上述首次实时验证是在这些日志完善前运行，原始记录没有逐图 SHA 字段。不能把驱动调用完成当成游戏动作成功；效果仍需下一张图核验。

验证命令：

```powershell
node --check scripts/browser_game_probe.mjs
node --test scripts/browser_game_probe.test.mjs
```

两项测试通过：6 类非法输入均被拒绝、像素截图与散列记录、正常关闭，以及拒绝覆盖已有证据目录。测试使用无头 about:blank，不会访问真实游戏或发送桌面输入。

## 工作台接入（同日后续）

工作台已增加显式 Browser 后端及 Ancient Beast 独立浏览器范围，两者必须同时选择。首版仅支持 Codex / 视觉 API，不调用本地模型；必须使用源码版现有 Node、frontend Playwright 和 Edge，不自动安装或回退到 Win32/Cua。尚未更新安装版。

`browser_execution.py` 和 `browser_worker.mjs` 复用共享执行核心及聊天 Agent 循环：只开放截图、坐标点击/移动、白名单按键、滚动和短等待。每次任务创建新的无头 Edge 上下文，结束或停止后清理自己的浏览器，不复用日常浏览器。模型输入仍为截图、任务和获准的经验；保留预算、停止、审计、B/C 来源及 R 审查绑定，不自动推广候选。

顶层页面越出官方 HTTPS 域名会终止任务；第三方嵌入页面被阻止。截图校验尺寸与 SHA-256，导航后旧观察对应的动作不发送；截图中途导航最多重拍三次，不重发输入。输入完成仅记为 `effect=unverifiable`，需后续画面验证，不能等同目标完成。

真实生产驱动 + 执行核心的独立验证保存在 `runs/browser-backend-validation-86920934/`：初始化导航触发旧观察拒绝，随后发送 Space，截图从菜单进入真实 Round 1 棋盘。没有调用模型。后续手工验证命令缺少统一计划信封，被执行核心拒绝，验证脚本的 finally 清理已执行；该次不能声称验证了生产后端的移动或完整回合。先前独立探针的移动/召唤证据仍与此次接入验证分开保存。

接入验证：相关 Python 回归 215 项、前端流程 30 项通过；浏览器 worker 7 项协议/隔离测试通过。前端类型检查、构建与改动范围 Ruff 检查通过。B → 浏览器任务 → R 来源绑定使用合成截图和模型替身验证，不代表真实游戏策略获得提升。

人工验证入口为 `scripts/validate_browser_backend.py`，从标准输入接收 `{"observe":true}`、`{"close":true}` 或统一动作计划（`actions` 数组），按最新截图逐步决定动作；不是自动通关脚本。

RSI 正式评测前还需固定游戏版本、可重复初始配置、隔离的胜负/目标验证，以及独立测试局面。保留原始示范与 B/C，改进仍走 R 候选审查；本次不改已有生产路径或自动推广候选。
