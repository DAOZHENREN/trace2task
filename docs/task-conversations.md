# 执行任务的连续上下文

- 当前执行入口只接受手动选择的 D 精简序列；旧任务包仍可在经验库查看，不删除已有文件，但不再作为执行经验。
- 完整 `model-input.txt` 在任务开始时加载为固定参考，不拆分、不摘要，不把它当作动作执行授权。
- Codex 复用原生 App Server thread，关闭自动摘要压缩。接近模型报告的窗口边界时，新 thread 重放全部历史文本（按原角色保存的完整字符串，不是摘要），只去掉历史图片；不再删除文字。接口没有提供移除图片的精确 token 数，日志明确标记不可测，不填估算值冒充实测。
- 自定义 API 使用无会话 ID 的 Chat Completions 协议，由客户端保存并重传完整对话。经验只在首条任务消息中出现一次。接近所配置的远端窗口预算时只清除 `_history` 中的图片附件，所有用户文字、模型回答和角色顺序保留。运行参数 `api_options.context_window_tokens` 是远端预算，默认 32768；本机无法测量远端 GPU 显存，这一项不用于本地 GUI 服务。
- 本地 GUI 服务维护任务会话。固定 system 仅承载工具协议和输出格式；首条 user 包含原始任务、约束、完整经验及首轮截图。后续规划 user 每轮新增 `Instruction: ` 加用户任务原文及当前截图，assistant 保留模型完整原始回答；不重复经验，也不重渲染整份每轮模板。自定义 `turn_template` 用于首条任务文字，旧反馈占位符保留兼容但展开为空。新增消息归档以组装后的实际 user 为准，首轮展示不会漏掉任务和经验。
- 后续客户端请求不重复上传 `prompt_profile` / 经验正文；服务端组装固定任务、历史及当前截图。执行器反馈和调用状态仅留在审计记录，不进入规划模型 messages，也不进入历史摘要。
- 每轮只新增一张当前截图；不再单独提交上一动作前对照图。历史截图仅通过历史消息保留。
- Transformers 本地后端不再设置 6144-token 输入上限或 5529-token 清理阈值。采用 CUDA 实时空闲显存、可回收分配器空间、模型 KV 结构、输入张量、视觉 / 预填充工作空间以及已测峰值作显存准入估计，保留 12% 总显存余量。估计不是显存保证；CUDA OOM 时释放本次临时张量，仅移除历史图片后重试推理，不重发动作。
- Transformers 后端清理最早的历史图片及对应 image 标记，不删除该轮用户文字、模型回答或完整经验。每次重新 tokenizer 计数，记录清理原因、来源轮次、前后 tokens、减少 tokens、显存估计和实际推理尝试。模型自身配置的原生窗口仍是有效边界；删完历史图片仍放不下时明确停止，不截断任何文本或当前截图。
- `request.json` 是客户端提交归档；`input.json` / `formatted-prompt.txt` / `tokenized-input.json` 是最终准备或实际推理输入（`input_stage` 明确区分）；`context-management.json` 记录清理与 token 差值；每次 OOM 重试的输入另存 `attempt-XX-input.json`，图片文件也不覆盖之前的尝试。
- 服务丢失或任务 ID / 模型 / 指令不匹配时明确拒绝，不自动退化成独立请求。新任务更换会话，不复用上一任务的截图或历史。
- 对话中的模型提议不等于执行事实；已发送、拒绝、未执行和效果未知的区分只在执行审计中保存。执行安全检查与停止机制不变。

- GUI-Owl 的 llama-server 后端现在复用 LangChain `SummarizationMiddleware`：预计上下文达到 24,576 tokens 时，把较早的观察/模型回答和已有摘要再摘要，保留最近 4 轮原文与图片。原始任务和完整经验独立保存，不送入摘要输入、不被摘要替换；压缩后仍作为首条 user 原文出现一次，后接摘要、近期对话和当前截图。旧图片不交给文字摘要模型，不编造其视觉细节。
- 摘要使用本机 Qwen 8B：临时卸载 GUI-Owl，加载文字摘要模型，结束后恢复 GUI-Owl；不借用独立的 8081 服务。摘要失败、截断、取消或恢复失败时，原对话不替换。旧原文仍在审计归档，不是重启后的自动恢复能力。
- 保留 LangChain 的触发与保留策略，但摘要提示词只整理模型提议、带来源的观察陈述和不确定事项，不使用默认的 SESSION INTENT / NEXT STEPS 模板猜测用户目标或宣告完成。摘要是可错的历史记忆，不能替代固定的原始要求。
- 每轮重复的原始任务提醒不送入摘要；首条任务原文和本轮任务提醒独立保留。仍使用既有 LangChain 压缩方式，不改成官方 cookbook 的 5 图裁剪策略。
- 聊天视图默认仅显示新增消息与当前图片，压缩发生时插入一次摘要事件；完整实际输入折叠保留。记录 `compaction.json`、摘要前文字、摘要请求/响应、被替换轮次和压缩后的实测输入 tokens。触发计数包含估计项，不冒充精确 tokenizer 计数。

`scripts/local_gui/validate_conversations.py` 使用合成色块验证真实 GPU 多轮输入与摘要后的保留后缀，不调用执行器、不操作桌面。详见 [llama-server 与摘要模块](llama-gui-backend.md)。
