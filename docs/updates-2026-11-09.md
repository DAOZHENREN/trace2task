# 2026-11-09 更新说明

## Windows 后台桌面

- 将 Windows 子桌面接入现有任务执行、截图、轨迹与经验提炼流程。
- 在选择后台桌面后显示连接管理，提供状态、实时查看与接管、关闭确认；任务结束后保留桌面供后续任务复用。
- 后台桌面读取主显示器分辨率和系统 DPI，查看窗口按比例显示。
- 改善启动、断连、清理及输入设备失败的诊断；用户接管导致画面过期时先重新观察。

## 基础知识生成

- 在基础知识管理中选择应用、知识范围、生成模型与思考强度，检索资料生成可编辑草稿。
- 支持多选知识范围及自定义范围；来源与待核实问题单独保存，正文面向 GUI Agent 的实际执行。
- 草稿确认保存后才能成为可复用知识；取消固定正文长度限制，并同步本地推理服务的首轮参考资料校验。

## 混合模型执行

- 指导模型分配有可见完成结果的阶段目标，使用 `fail_conditions` 描述需要指导的失败条件；保留旧轨迹字段兼容。
- 通过阶段操作数、执行反馈与完成报告调整目标粒度；执行模型明确区分进行中、阶段完成和阶段失败。
- 执行模型首轮同时加载基础知识和选中的完整经验正文，后续多轮对话保留参考内容；`notices` 提供阶段相关提醒和约束。
- 明确执行端坐标为截图上各轴归一化的 `0..1`，避免将像素坐标用于点击。
- 连续相同非等待动作达到配置阈值后交回指导复查，即使游戏动画使截图变化也不会绕过检查；截图变化不再被当作操作有效的证据。

## 验证边界

自动化回归覆盖模型协议、后台桌面生命周期、知识草稿、任务界面与轨迹展示。离线测试和输入回执不代表真实游戏任务成功，也不保证每台 Windows 设备的 RDP 配置均可使用。后台桌面仍需要系统 Child Sessions、本机 RDP 与 Cua Driver。
