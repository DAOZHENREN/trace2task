# Trace2Task

**Record once. Benchmark every agent.**

Trace2Task aims to turn a successful human workflow into a resettable, verifiable benchmark task for browser, GUI, and mobile agents.

## Goal

- Record human workflows and the environment state before and after.
- Compile each trace into a reusable task pack with reset and verification.
- Evaluate different agents by outcomes and side effects, not by replaying the exact path.

## Status

Early-stage exploration. The first milestone will focus on local browser agents.
