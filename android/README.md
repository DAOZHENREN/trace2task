# Trace2Task Android — 0.2.0 cloud-first preview

原生 Android APP，直接操作**手机上的应用**。运行时不需要电脑、ADB、Root 或 Windows Cua。
首版支持 Android 11 / API 30 及以上，使用用户手动开启的 AccessibilityService 截图、手势和文本输入。

## 已实现范围

- 用户在手机填写 HTTPS Chat Completions 完整地址、支持图片的模型 ID 和自己的 API Key。
- 选择一个目标应用，输入任务，启动后模型**直接执行，不逐步确认**。
- 每轮：检查目标 → 截图 → 云端规划一个动作 → 本地重新截图检查变化 → 执行 → 等待回执 → 重新观察。
- 支持点击、长按、滑动、替换已聚焦文本框内容、返回和等待。
- 悬浮停止按钮、音量下键急停、1–100 轮上限、重复动作限制、网络/截图/手势超时。
- 人工示范：离线记录无障碍点击、长按、滚动、文本变化事件及事件后的抽样截图，可手动标记画面。
- 编译经验：预览示范后，明确同意上传选定证据，由云端生成语义步骤、前置条件、验收条件和风险提示。
- 根据经验执行：固定所选版本，每轮连同当前任务和最新截图交给模型重新规划；不机械回放旧坐标，不逐步确认。
- 反馈修订：先本地保存人工反馈，再调用模型生成独立的新版本；原始示范和旧版本保留，失败不覆盖旧经验。
- 执行截图不持久保存；最近一次运行保存脱敏动作记录和经验版本 ID。**主动录制**的任务、事件、文字、截图，以及生成的经验和反馈会在私有经验库持久保存。
- API Key 使用 Android Keystore AES-GCM 加密，关闭应用备份；配置页面禁止截图。

这是可安装的开发预览，不是已通过所有手机兼容性测试或商店审核的正式发行版。
没有跨应用流程、完整原始触摸/视频录制、录音解说、离线模型或电脑配对功能；Windows 功能保持原样。

## 使用

1. 安装自行构建的 debug APK（系统会要求允许该来源安装）。
2. 填写完整地址，例如 `https://your-provider.example/v1/chat/completions`、模型 ID、API Key。不要把密钥填进 URL。
3. 点击“保存模型配置”。这一步**不会发起模型请求或产生 API 费用**。
4. 点击“启用无障碍服务”，阅读说明后在系统中手动开启 Trace2Task。
   部分侧载设备可能额外要求用户允许“受限设置”；APP 不会代替用户授权或绕过限制。
5. 选择目标应用，填写一个可观察的小任务，设置最大轮数；同意本次截图上传与自动操作后启动。
6. 系统打开目标应用；约 1.8 秒后开始。请保持屏幕解锁、亮屏，不要同时手动操作。
7. 点击悬浮“停止任务”或按音量下键终止。返回 Trace2Task 可看到最终停止原因。

## 人工示范 → 经验 → 执行 → 反馈修订

1. **录制人工示范**：在主页选择应用，任务框填写示范目标；勾选本地录制说明，点击“录制人工示范”。录制不需要 API Key，也不调用模型。等悬浮状态变为录制中，再人工操作。
2. 点击“标记当前画面”可补充关键页面检查点。结束时点击“结束并保存示范”或按音量下键；回到主页进入“示范与经验库”。录制与自主执行互斥，不会把模型动作混成新的人工示范。
3. **编译可复用经验**：先预览示范事件和截图，勾选上传说明，点击“编译可复用经验 · Trace Compile”。再次核对来源、截图数量、目标服务和模型后生成。
4. 查看生成经验，点击“设为下次执行的经验版本”；返回主页选择同一个应用，输入**本次任务**（可改变搜索词等参数）并启动。应用不匹配会拒绝启动。当前任务和画面优先，经验只是参考，不扩大操作权限。
5. **人工反馈修订**：运行后在经验库选中需要改进的版本，写明失败现象、正确操作或验收条件，点击“保存反馈并生成新版本 · Feedback Revision”。修订使用该版本关联的原始示范，不受示范下拉框其他选择影响。
6. 查看并选择修订版，再运行。也可从下拉框重新选择旧版，或取消经验选择进行无经验执行。生成新版本不会自动切换正在运行的任务。

编译和修订最多等待 90 秒，可取消；离开经验库页面也会取消。迟到结果不发布，已发送请求可能已经产生费用。
失败时旧经验与已保存的反馈保留；反馈列表可查到生成失败前保存的文字。服务/进程意外中断留下的 `recording` 草稿可继续作为不完整证据查看/编译，不表示仍在录制或示范成功。

### 录制与经验的真实性边界

- 每次最多 **80 条事件、12 张抽样截图、5 分钟**；图片总量也有上限。达到截图上限后事件仍可记录，元数据会标记截图覆盖不足。
- 无障碍事件可能合并、缺失或由应用程序自身产生，**不能证明每条都来自人的触摸**。自绘/游戏界面、返回手势和部分键盘动作尤其容易缺失。
- 节点矩形不是实际触摸坐标。截图在事件后延迟抽样，可能夹杂其他动作，**不是精确的逐动作前后帧**；结束前未完成的截图可能缺失。
- 手动画面标记只是检查点，不伪造点击/滑动记录。编译保存来源事件引用；未知事件引用、越界字段、截断或格式错误的模型输出不会发布。
- 编译版与修订版均保存来源 ID、证据限制、目标应用；修订还保存父版本和反馈 ID。经验不是已验证的成功流程，运行 `done` 也仍是未独立验收。

首次建议使用无个人数据的测试应用：输入文本或搜索一项内容。不要用支付、发送消息、购买或删除数据作为首次验证任务。
停止会取消请求并使迟到回调失效，但**已经投递的点击、文本输入或正在执行的手势不能撤回**。

## 云端接口与隐私边界

当前 `CloudModelClient` 调用 `/chat/completions`，请求包含 `model`、`messages`、`stream:false`、
执行时 `max_completion_tokens:1024`。用户消息包含任务、所选经验及其证据限制、最近 8 条脱敏动作记录与 `image_url` PNG data URL。
编译/修订使用 `max_completion_tokens:6000`，发送选定示范的任务、事件、全部已保存抽样截图；修订还发送父版本经验和人工反馈。
服务必须支持上述参数和图片输入，并返回 `choices[0].message.content` 字符串及 `finish_reason:"stop"`。
**不是任意标称“兼容”服务都已实测**；不支持此参数、拒绝图片、限额或鉴权失败会停止，不会自动重试计费请求。

截图最长边缩小到 1280，包含系统状态栏、当前可见的键盘和可能出现的通知等内容。数据会发送到**你填写的服务商**，
其留存、训练使用及费用由该服务商的规则决定；执行截图不在本机持久保存不等于云端不留存。
录制证据、经验和反馈保存于应用私有 `files/experience-library/`，不进相册、不参与备份；它们**不使用应用级文件加密**，不应录制敏感信息。
系统“清除应用存储”或卸载会删除本机库（没有自动云同步/恢复）；主页清除 API 配置不会删除经验库。
不内置共享密钥，不读取电脑的密钥，不关闭 TLS 校验，不跟随重定向，不支持明文 HTTP。
BYOK 仅适合个人预览；分发给其他人时，每个人填写自己的凭据，不能把开发者密钥嵌入 APK。

任务只授权选定应用。离开目标应用、旋转/窗口变化、锁屏、截图被系统拒绝、已聚焦密码框、协议非法或回执超时均停止或丢弃旧计划。
前后图片的缩略比较只是变化检测启发式，不能证明所有小范围变化都已被发现。
支付等敏感行为有提示词限制，**不是完备的运行时识别或安全保证**；自主执行存在误操作风险。
`done` 只表示模型要求结束，UI 明确标记“未独立验收”，不会将它当作已验证成功。
游戏、受保护窗口、工作资料、定制系统、系统授权页及部分自绘输入框可能不支持截图/手势/文本操作。

## 构建与测试

需要 JDK 17+（推荐 17）、Android SDK Platform 35、Build Tools 35.0.0；Android Gradle Plugin 8.7.3 / Gradle 8.9。
在 Android Studio 打开本目录，或设置 `JAVA_HOME`、`ANDROID_HOME` 后：

```powershell
cd android
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

Linux/macOS 使用 `sh ./gradlew testDebugUnitTest lintDebug assembleDebug`。
首次构建需要联网下载固定版本依赖。单元测试不调用真实模型，不需要 API Key。
APK：`app/build/outputs/apk/debug/app-debug.apk`；debug 签名仅用于开发预览。
正式发行前需要自有发布签名、隐私披露、无障碍 API 政策评估和真机验收，不能直接视作已具备商店上架资格。

真机安装（仅开发时需要电脑）：

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

不自动开启手机调试、授予无障碍权限、连接陌生设备或替换正式签名的安装包。

## 验收清单

2026-10-02 本机验证：`testDebugUnitTest lintDebug assembleDebug` 构建成功，33 项 JVM 单元测试通过，
Android Lint 0 错误 / 0 警告，debug APK 通过 `apksigner verify`。
当时 ADB 未连接设备，也未配置真实云端凭据，因此以下真机/API 联调项目**尚未验证**：

- [ ] Android 11 与较新 Android 真机能手动启用服务、显示停止控件。
- [ ] 在无敏感数据的应用里，云端返回 click / drag / type_text，画面产生预期变化。
- [ ] 模型请求过程中按音量下键：迟到回复不执行，也不触发下一轮。
- [ ] 连续点击开始不会产生两个任务；停止后重启不接受旧任务回调。
- [ ] 切换应用、旋转屏幕、锁屏时不向旧坐标发送输入。
- [ ] 安全窗口/密码框不上传截图；API 401/429、超时、非法 JSON 不执行动作。
- [ ] 达到轮数上限、重复动作、手势取消时停止，模型结束不显示“已验证成功”。
- [ ] 不同 DPI/横竖屏/导航方式下，点击使用截图的物理像素坐标。
- [ ] 离线人工录制后预览：事件与截图来自目标应用，密码事件不保存，音量下键能保留部分示范。
- [ ] 真实云端编译示范，正确关联来源；响应格式错误、取消或断网不产生新版本。
- [ ] 同一经验改任务参数或页面布局后，按最新画面重规划成功（不能只凭单元测试宣称成功）。
- [ ] 反馈修订生成新版；选中新版复用，重新选旧版可回退；失败反馈仍可查看。
- [ ] 意外结束进程后的不完整示范仍能读取，截图上限与未完成截图提示清楚。

## 后续接电脑的接口边界

`ModelClient.predict(task, pngBase64, history) -> ActionPlan` 与手机的观察/执行分离。
未来可实现 `PairedPcModelClient`，由受认证的电脑服务返回同一手机动作计划；手机仍负责范围校验、急停与实际执行。
目前**未实现配对或复用桌面服务接口**，不能仅改 URL 就宣称电脑接入已完成。
动作沿用桌面 `observation_normalized_0_1` 概念，但这是 Android 的受限方言（例如 `long_press`、`back`），不是未经转换即可发送到 Windows 的完整协议。
